# 考研英语长难句分析工具

一个**单文件、纯前端**的考研英语长难句精析工具。粘贴一段英文文章，它会调用 DeepSeek API 通读断句，逐句划出句子成分、标注重难点词汇，并给出整句译文。

> 所有数据都在你自己的浏览器里处理：API Key 与缓存只写入 `localStorage`，不会上传到任何第三方服务器。

---

## 功能

**断句与成分分析**
- 先让 AI 通读全文断句（失败自动回退到内置的本地规则断句，缩写、小数点、省略号都能正确处理）
- 逐句切分语法成分：主语 / 谓语 / 宾语 / 表语 / 定语 / 状语 / 补足语 / 定语从句 / 同位语 / 插入语
- **加粗黄底 = 句子主干，彩色字 = 修饰成分，色块 = 从句/同位语/插入语**
- 每句都有中文译文，可整句复制

**词汇**
- 自动抽取考研难度的重难点词汇与固定搭配，右侧栏按原文顺序列出
- 单击词表条目可跳转定位到原文
- 侧栏图例可点击筛选，只看某一类成分

**查词**
- 单击单词/词组 → **荧光笔涂黄**标记（同一时刻只保留一处，再点一次取消）
- 双击单词 → 调 AI 详解（语境含义、用法搭配、例句），结果会缓存
- 触屏设备：**长按单词 500ms** 触发 AI 详解
- 在原文里选中任意词再双击，也能用整句作上下文查词

**可自定义 AI 解词提示词**
- 顶栏齿轮按钮（或解词弹窗里的「编辑提示词」）
- 支持占位符：`{word}` 当前单词、`{sentence}` 所在句子、`{trans}` 该句译文、`{context}` 所在段落、`{extra}` 额外要求、`{schema}` 输出格式
- 实时预览：用示例值把提示词渲染出来，所见即所发
- `{word}` 与 `{schema}` 属于必需占位符，缺了会拦住保存
- 改了提示词，旧的解词缓存自动失效（缓存键带提示词指纹）

**缓存**
- 分析结果与解词结果缓存在本地，重看同一篇文章不消耗 API 额度
- **超过 7 天没有访问过的缓存自动清除**，最多保留 40 条
- 顶栏垃圾桶按钮可查看占用、手动清理过期缓存或全部清空

**多端适配**
- 桌面 / 平板 / 手机三档断点
- 窄屏顶栏自动收拢为「更多」菜单
- 手机端「核心词汇」折叠为可展开的底部面板
- 触屏去掉了 hover 视觉残留，补上长按交互

**其它**
- 打印 / 导出 PDF（自动展开全部精析）
- 支持粘贴文本或上传图片识别（走 DeepSeek 视觉接口转录文字）
- 显示偏好记忆：译文显隐、释义显隐、翻译显示模式、标注区字体（衬线/无衬线）

## 使用方法

1. 打开 `index.html`（双击即可，或访问部署好的在线地址）
2. 点右上角 **设置 API Key**，填入你自己的 DeepSeek API Key
   - 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建
   - Key 只保存在你浏览器的 `localStorage` 里
3. 粘贴考研英语文章（1000 词以内效果最佳，段落之间用空行分隔）
4. 点「开始分析」

> 想先看效果可以点「载入示例」，它内置了一段考研真题风格的短文。

---

## 部署到 GitHub Pages

1. 把这个仓库的 `index.html` 放在根目录（本来就是）
2. 仓库 **Settings → Pages**
3. Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

单文件应用，没有构建步骤，改完直接提交即可。

## 说明与边界

- **需要自备 API Key**，分析会消耗你自己的 DeepSeek 额度。并发 3 批、每批 5 句，可用文件顶部的 `BATCH_SIZE` / `CONCURRENCY` / `MAX_TOKENS` 调整。
- **断句失败会自动降级**为本地规则断句，界面会明确提示「本地规则断句」，不会静默出错。
- **标注会有误差**。成分划分由模型生成，遇到特别刁钻的句子可能标错；工具会做词边界校正与「原文逐字还原」校验，保证**不会丢字或重复**，但语法判断请以教材为准。
- 分析失败的单句可以在句内点「重试」，不会整篇重跑。
- 浏览器直连 DeepSeek API，若你的网络环境需要代理，请确保浏览器能访问 `api.deepseek.com`。

## 技术实现

- 零依赖、零构建，单个 HTML 文件（HTML + CSS + 原生 JS）
- 标注渲染不用第三方库：自己实现的分词 → 成分区间对齐 → 逐单元着色，并有「原文逐字还原」的自动化校验
- 缓存带版本前缀、统一索引、访问时间戳与 TTL
